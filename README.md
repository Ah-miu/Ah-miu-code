# Ah-miu: Rethinking the Gaps Between Physical AI and Us, from Machines to Human Needs

All the core components shown in this demo have been running in my personal setup for at least 3 months.

I'm currently working on extracting and organizing the relevant core code behind the Ah-miu demo from my existing system.

Over the next 2–3 weeks, I'll gradually update technical details and selected implementations on my blog.

Topics will include:

- **Real-time, high-FPS, high-resolution multi-camera wireless video streaming**
- **Efficient storage and management of long-term video memory**
- **The sparsity of high-salience interactions, the proactivity of interactive systems, and the transferability of interaction trajectories**
- **Hacking by talking: Efficient Multimodal Auto-Hack for Everyday People**

Feel free to follow me on [Twitter / X](https://x.com/jinghan_ke) for updates.

Thanks everyone for your interest and patience!
